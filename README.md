Featured Projects
[PenTest Toolkit](Offensive_Security/PenTest-Toolkit/README.md)
Network diagnostics and security testing application

A full-stack application that integrates Nmap and Gobuster into a user-friendly interface for authorized lab testing.
- Run and review Nmap scans for host, port, and service discovery.
- Perform web directory enumeration with Gobuster.
- Organize activity using workspaces and persistent scan history.
- Review structured results and export scan reports.
- Work with a React/TypeScript frontend, Python FastAPI backend, and SQLite database.
Relevant skills: TCP/IP networking, ports and services, HTTP, troubleshooting, REST APIs, Python, TypeScript, and technical reporting.
[Security Monitoring System](Defensive-Security/Security-Monitoring-System/READ.md)
Python-based security monitoring and alerting

A project exploring how system and network activity can be monitored to identify potentially suspicious events.
- Detect patterns of repeated failed login attempts.
- Monitor selected files for integrity changes.
- Identify potential port-scanning activity.
- Generate alerts and display a summary dashboard.
Relevant skills: Python scripting, log analysis, system monitoring, troubleshooting, and security event detection.
