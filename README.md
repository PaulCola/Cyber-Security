Featured Projects
[PenTest Toolkit](./Offensive_Security/PenTest-Toolkit/)
Network diagnostics and security testing application

A full-stack application that brings Nmap and Gobuster into a centralized interface for authorized lab testing.
- Run Nmap scans and review discovered ports and services.
- Perform web directory enumeration using Gobuster.
- Organize scans by workspace and review saved scan history.
- Export structured scan results in TXT and JSON formats.
- Work across a React/TypeScript frontend, Python FastAPI backend, and SQLite database.
Skills demonstrated: Networking fundamentals, HTTP, troubleshooting, REST APIs, Python, TypeScript, and technical reporting.
[Security Monitoring System](./Defensive-Security/Security-Monitoring-System/)
Python-based system and network monitoring

A modular project that explores how suspicious activity can be detected and reported.
- Detect repeated failed authentication attempts within a configurable time window.
- Monitor files for changes, deletion, and restoration.
- Identify potential port-scanning patterns.
- Generate alerts and review summary information through a dashboard.
Skills demonstrated: Python scripting, log analysis, system monitoring, automation, and troubleshooting.
