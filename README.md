## Featured Projects

### 1. PenTest Toolkit

**[View PenTest Toolkit](./Offensive_Security/PenTest-Toolkit/)**

A full-stack network diagnostics and security testing application that integrates Nmap and Gobuster into a centralized interface.

**Key features:**
- Execute Nmap scans to identify open ports and network services.
- Perform web directory enumeration using Gobuster.
- Organize scans into workspaces.
- Review saved scan history.
- Export results in TXT and JSON formats.
- Manage frontend and backend communication through REST APIs.

**Technologies:** React, TypeScript, Python, FastAPI, SQLite, Nmap, Gobuster.

**Skills demonstrated:** Networking fundamentals, service discovery, troubleshooting, API integration, and technical reporting.

### 2. Python Security Monitoring System

**[View Security Monitoring System](./Defensive-Security/Security-Monitoring-System/)**

A Python-based security monitoring application designed to identify suspicious system and network activity.

**Key features:**
- Detect repeated failed authentication attempts.
- Monitor files for modifications, deletions, and restoration.
- Identify potential network port-scanning activity.
- Generate security alerts based on configurable thresholds.
- Display alert summaries through a monitoring dashboard.

**Technologies:** Python, file integrity monitoring, network detection, logging.

**Skills demonstrated:** Python scripting, system monitoring, log analysis, troubleshooting, and automation.
