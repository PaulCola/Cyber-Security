## Featured Project

### Python Security Monitoring System

**[View Security Monitoring System](./Security-Monitoring-System/)**

A Python-based security monitoring application designed to identify suspicious system and network activity through multiple detection modules.

The application integrates three primary monitoring components:

**1. Brute Force Detection**
- Monitors failed authentication attempts.
- Identifies repeated login failures within a configurable time window.
- Generates alerts when suspicious authentication activity exceeds a defined threshold.

**2. File Integrity Monitoring**
- Monitors designated files for unauthorized or unexpected changes.
- Detects file modifications, deletions, and restoration.
- Generates security alerts when monitored files change.

**3. Network Activity Detection**
- Analyzes network activity for potential port-scanning behaviour.
- Tracks unique destination ports within a specified time window.
- Generates alerts when suspicious scanning patterns are detected.

### Additional Functionality
