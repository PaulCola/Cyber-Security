## Featured Project

### Windows IT Support Diagnostics Tool

**[View Project](./IT-Support-Diagnostics/)**

A PowerShell-based diagnostic application designed to automate common Windows troubleshooting tasks and generate structured reports for IT Support investigations.

**Key Features:**
- Retrieves Windows system information, including operating system, processor, RAM, and uptime.
- Identifies network configuration, including IPv4 addresses, default gateways, and DNS servers.
- Tests gateway connectivity, DNS resolution, and HTTPS connectivity.
- Monitors available disk space and selected Windows services.
- Identifies potential technical issues and provides troubleshooting recommendations.
- Generates timestamped diagnostic reports that can support help desk investigations.

**Technologies Used:**
- PowerShell
- Windows CIM
- Windows networking cmdlets
- Windows service management
- Git and GitHub

**Skills Demonstrated:**
- Windows troubleshooting and system administration
- TCP/IP and DNS diagnostics
- PowerShell scripting and automation
- System health monitoring
- Technical documentation and reporting
- Problem identification and troubleshooting

## Project Testing

The diagnostics application was tested in a Windows 11 environment.

Testing included successful network connectivity checks, detection of low available disk space, simulation of a DNS resolution failure, and generation of diagnostic reports.
