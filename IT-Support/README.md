## Featured Projects

### 1. Windows IT Support Diagnostics Tool

**[View Project](./IT-Support/IT-Support-Diagnostics/)**

A PowerShell-based diagnostic application that automates common Windows troubleshooting tasks and generates reports for IT Support investigations.

**Key Features:**
- Retrieves Windows system information, including operating system, CPU, RAM, and uptime.
- Identifies IPv4 addresses, default gateways, and DNS configurations.
- Tests network connectivity, DNS resolution, and HTTPS access.
- Monitors disk space and important Windows services.
- Identifies potential system issues and provides troubleshooting recommendations.
- Generates timestamped diagnostic reports.

**Technologies:** PowerShell, Windows CIM, Windows networking cmdlets.

**Skills Demonstrated:** Windows troubleshooting, PowerShell automation, network diagnostics, system monitoring, and technical documentation.

### 2. PenTest Toolkit

**[View Project](./Offensive_Security/PenTest-Toolkit/)**

A full-stack network diagnostics and security testing application that integrates Nmap and Gobuster into a centralized interface.

**Key Features:**
- Executes Nmap scans to identify open ports and network services.
- Performs web directory enumeration using Gobuster.
- Organizes scans into workspaces.
- Maintains scan history.
- Exports scan results in TXT and JSON formats.
- Integrates a React frontend with a Python FastAPI backend.

**Technologies:** React, TypeScript, Python, FastAPI, SQLite, Nmap, Gobuster.

**Skills Demonstrated:** Networking fundamentals, service discovery, troubleshooting, API integration, and technical reporting.

### 3. Python Security Monitoring System

**[View Project](./Defensive-Security/Security-Monitoring-System/)**

A Python-based monitoring application designed to identify suspicious system and network activity.

**Key Features:**
- Detects repeated failed authentication attempts.
- Monitors files for modifications, deletion, and restoration.
- Identifies potential network port-scanning activity.
- Generates configurable security alerts.
- Displays monitoring summaries.

**Technologies:** Python, logging, file integrity monitoring, network detection.

**Skills Demonstrated:** Python scripting, system monitoring, log analysis, troubleshooting, and automation.
