## Penetration Testing Methodology

My approach to penetration testing follows a structured process to ensure findings are investigated systematically and documented clearly.

### 1. Reconnaissance

Gather initial information about the target environment, including network accessibility, exposed services, and available resources.

**Skills practiced:**
- Network connectivity testing.
- Host and port discovery.
- Initial service identification.

### 2. Enumeration

Investigate discovered services to better understand the target system and identify potential security weaknesses.

**Skills practiced:**
- Service and version identification.
- Web directory enumeration.
- HTTP response analysis.
- File and resource discovery.

### 3. Vulnerability Investigation

Review identified services, configurations, and exposed resources for weaknesses that could affect system security.

**Skills practiced:**
- Identifying insecure configurations.
- Investigating exposed information.
- Evaluating potential attack paths.
- Researching technical findings.

### 4. Controlled Exploitation

Where permitted by the lab environment, test identified weaknesses to understand their potential security impact.

**Skills practiced:**
- Working with Linux command-line environments.
- Understanding authentication and access controls.
- Investigating system permissions.
- Exploring privilege escalation concepts.

### 5. Documentation & Reporting

Record the investigation process, relevant technical evidence, and final results.

**Skills practiced:**
- Organizing technical findings.
- Documenting commands and results.
- Explaining security issues clearly.
- Developing reproducible investigation notes.
