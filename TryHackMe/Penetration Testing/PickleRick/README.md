# Pickle Rick — TryHackMe

### Network Enumeration | Web Security | Linux Privilege Escalation

## Overview

Pickle Rick is a TryHackMe penetration testing lab focused on network reconnaissance, web application enumeration, and Linux privilege escalation.

The objective was to investigate a vulnerable machine, identify potential security weaknesses, and obtain the required information through authorized testing.

## Tools Used

- Nmap
- Linux command-line utilities
- Web browser
- Python

## Skills Demonstrated

- Network scanning and service identification
- Web application enumeration
- Linux file system navigation
- User permissions and privilege escalation
- Technical troubleshooting and documentation

## Key Takeaways

This lab strengthened my understanding of how network services, web applications, and Linux permissions interact.

It also provided practical experience following a structured investigation process, analyzing technical findings, and documenting results.
