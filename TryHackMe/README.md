# TryHackMe Labs & Practical Cybersecurity Training

### Hands-On Learning | Network Security | Linux Fundamentals | Penetration Testing

This section of my cybersecurity portfolio documents my practical learning experiences through [TryHackMe](https://tryhackme.com/), an interactive platform offering hands-on cybersecurity labs and simulated environments.

Through these labs, I develop technical skills in **networking, system enumeration, troubleshooting, vulnerability identification, and Linux administration**.

My goal is to strengthen my understanding of how systems and networks operate, how security weaknesses can be identified, and how technical problems can be investigated and resolved.

## Tools & Technologies

Tools used throughout my practical cybersecurity training include:

- **Nmap** — Network discovery, port scanning, and service enumeration.
- **Gobuster** — Web directory and resource enumeration.
- **Netcat** — Network connectivity testing and command-line communication.
- **Linux Terminal** — File system navigation, permissions, and system investigation.
- **SSH** — Remote system access and administration.
- **Python** — Scripting and technical problem-solving.
- **Wireshark** — Network packet inspection and protocol analysis.

Tools vary depending on the lab and its objectives.
